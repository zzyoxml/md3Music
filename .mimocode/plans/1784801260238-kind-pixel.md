# 参考 applemusic-like-lyrics 重写高斯模糊

## 核心改动
采用参考代码的**距离驱动 blur level 算法**，替换当前的固定分区方案。保留 BackdropFilter 渲染方式（歌词用 CustomPaint 渲染，无法 per-line ImageFiltered）。

### 参考算法（`computeLineBlur`）
- 当前行：blur = 0
- 已过行：blur = 1 + |currentLine - lineIndex| + 1
- 未到行：blur = 1 + |lineIndex - currentLine|
- 用户滚动时：所有行 blur = 0

### sigma 换算
参考代码 CSS blur px → Flutter sigma：`sigma = blurPx / 2`
- blurLevel=1 → sigma=0.5
- blurLevel=3 → sigma=1.5  
- blurLevel=5 → sigma=2.5（spring 模式上限）

## 修改文件
`lib/widgets/apple_lyrics/apple_lyrics_view.dart`

## 具体改动

### 1. 新增 `_computeLineBlur` 方法
```dart
int _computeLineBlur(int lineIndex) {
  if (_currentLineIndex < 0 || lineIndex == _currentLineIndex) return 0;
  if (_scrollController.isUserScrolling) return 0;
  int blurLevel = 1;
  if (lineIndex < _currentLineIndex) {
    blurLevel += (_currentLineIndex - lineIndex).abs() + 1;
  } else {
    blurLevel += (lineIndex - _currentLineIndex).abs();
  }
  return blurLevel > 5 ? 5 : blurLevel; // spring 模式上限 5
}
```

### 2. 修改 `_buildBlurLayers`
- 移除固定分区逻辑
- 使用 `_computeLineBlur` 对每个可见行计算 blur level
- 将 blur level 转换为 sigma 并生成 BackdropFilter 层
- sigma = `_computeLineBlur(i) * 0.5 * _blurIntensity`

### 3. 移除不再需要的字段
- `_blurTarget`（用户滚动清零由 `_computeLineBlur` 处理）

### 4. `_onVerticalDragUpdate` 中不清零 `_blurIntensity`
改为：`_computeLineBlur` 检查 `_scrollController.isUserScrolling`

### 5. `LyricScrollController` 暴露 `isUserScrolling`
添加 getter（`_isUserScrolling` 当前是 private）。
同时移除 `_blurIntensity` 相关逻辑（用户滚动清零由 `_computeLineBlur` + `isUserScrolling` 处理）。

## 验证
1. 当前行清晰，已过行和未到行根据距离递增模糊
2. 拖动歌词时所有行 blur 清零
3. 松手后 blur 恢复
4. blur 最大 sigma = 2.5（柔和，不遮挡文字）
