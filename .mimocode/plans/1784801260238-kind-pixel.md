# 设置页添加高斯模糊开关

## 目标
在设置页"Apple Music 风格播放页"开关下方添加"歌词高斯模糊"开关，控制歌词视图使用高斯模糊还是 alpha 渐变淡出。AM 风格播放页关闭时该开关置灰不可用。

## 修改文件

### 1. `lib/widgets/apple_lyrics/layout/lyric_preferences.dart`

新增 `useGaussianBlur` 偏好：

```dart
static const String _keyUseGaussianBlur = 'lyric_use_gaussian_blur';
bool _useGaussianBlur = true; // 默认开启高斯模糊

bool get useGaussianBlur => _useGaussianBlur;

Future<void> setUseGaussianBlur(bool enabled) async {
  if (_useGaussianBlur == enabled) return;
  _useGaussianBlur = enabled;
  notifyListeners();
  final prefs = await SharedPreferences.getInstance();
  await prefs.setBool(_keyUseGaussianBlur, enabled);
}
```

在 `load()` 和 `reset()` 中加入读取/重置。

### 2. `lib/modules/settings/settings_page.dart`

在 AM 风格播放页 `SwitchListTile`（行 391-399）之后添加：

```dart
SwitchListTile(
  title: const Text('歌词高斯模糊'),
  subtitle: const Text('开启为高斯模糊渐变，关闭为 alpha 淡出'),
  value: LyricPreferences.instance.useGaussianBlur,
  onChanged: _useAmStylePlayer
      ? (v) => LyricPreferences.instance.setUseGaussianBlur(v)
      : null,  // AM 关闭时置灰
),
```

### 3. `lib/widgets/apple_lyrics/apple_lyrics_view.dart`

在 `build` 方法中根据 `LyricPreferences.instance.useGaussianBlur` 切换：

- `true`：使用当前的 `_buildBlurLayers`（BackdropFilter 高斯模糊）
- `false`：使用原来的 `ShaderMask` + `LinearGradient` + `BlendMode.dstIn`（alpha 淡出）

alpha 淡出代码（恢复旧实现）：
```dart
child: ShaderMask(
  shaderCallback: (Rect bounds) {
    return LinearGradient(
      begin: Alignment.topCenter,
      end: Alignment.bottomCenter,
      colors: const [Color(0x00000000), Color(0xFF000000), Color(0xFF000000), Color(0x00000000)],
      stops: const [0.0, 0.15, 0.85, 1.0],
    ).createShader(bounds);
  },
  blendMode: BlendMode.dstIn,
  child: ClipRect(child: CustomPaint(...)),
)
```

## 验证
1. 设置页显示"歌词高斯模糊"开关，在 AM 风格播放页开关下方
2. AM 风格关闭时，高斯模糊开关置灰
3. 开启高斯模糊 → 歌词视图使用 BackdropFilter 高斯模糊
4. 关闭高斯模糊 → 歌词视图使用 alpha 渐变淡出
5. 切换即时生效，无需重启
