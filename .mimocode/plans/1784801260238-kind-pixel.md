# 歌词弹簧延迟上拉级联动画

## 目标
当前行切换到下一行时，下方歌词逐级延迟上移：下一行延迟启动，再下一行等前一行动了之后再延迟同样时间，形成波浪式级联效果。上方歌词正常上移无延迟。上移有运动阻尼（非线性弹簧动画）。

## 核心机制

### 坐标系统
```
屏幕 Y = lineTops[i] + interludeOffset + posY + perLineOffset[i]
```
- `lineTops[i]`：行在内容空间的累计顶部位置（静态）
- `posY`：全局滚动偏移（单一 Spring 驱动，所有行同步移动）
- `perLineOffset[i]`：**新增**每行独立偏移（Spring 驱动，默认 0）

### 级联延迟触发
当前行从 N 切换到 N+1 时：
1. 行 N+1：延迟 50ms → Spring 从 -40px 动画到 0（向上移动 40px）
2. 行 N+2：延迟 100ms → Spring 从 -40px 动画到 0
3. 行 N+3：延迟 150ms → Spring 从 -40px 动画到 0
4. ...逐级递增，视口外的行不参与

### 视觉效果
- 行 N+1 在全局滚动基础上额外"滞后"40px，然后弹簧上拉到最终位置
- 行 N+2 滞后更久，形成波浪式延迟
- 上方已完成的行无偏移（offset = 0），不受影响
- 弹簧用欠阻尼参数，有轻微过冲，运动是非线性的

## 修改文件

### 1. `lib/widgets/apple_lyrics/apple_lyrics_view.dart`

#### 新增字段
```dart
// 每行偏移弹簧缓存（行索引 → Spring）
final Map<int, Spring> _perLineSprings = {};
// 每行延迟计时器（行索引 → 延迟开始时间戳）
final Map<int, double> _delayStartTimes = {};
// 当前级联的目标行索引（-1 = 无级联）
int _cascadeTargetLine = -1;
```

#### 常量
```dart
static const double _perLineDelayMs = 50.0;  // 每行延迟 50ms
static const double _perLineOffset = -40.0;  // 初始偏移 -40px（向下）
// 弹簧参数：欠阻尼，轻微过冲
static const double _perLineSpringMass = 1.0;
static const double _perLineSpringDamping = 15.0;
static const double _perLineSpringStiffness = 100.0;
```

#### `_onTick` 中新增逻辑（在 blur intensity 之后，setState 之前）
```dart
// 级联弹簧：检测当前行变化
if (_currentLineIndex != _previousLineIndex && _currentLineIndex >= 0) {
  _cascadeTargetLine = _currentLineIndex;
  final now = _lastElapsed.inMicroseconds / 1000.0;
  // 为当前行下方的行设置延迟和弹簧
  for (int i = _currentLineIndex + 1; i < widget.lines.length; i++) {
    _delayStartTimes[i] = now;
    _getOrCreateSpring(i).setPosition(_perLineOffset, 0);
    _getOrCreateSpring(i).setTarget(0);
  }
  // 清除更早的级联状态
  _delayStartTimes.removeWhere((k, _) => k < _currentLineIndex);
}
_previousLineIndex = _currentLineIndex;

// 推进每行弹簧
for (final entry in Map.of(_perLineSprings).entries) {
  final i = entry.key;
  final spring = entry.value;
  if (i < _currentLineIndex || i >= widget.lines.length) {
    // 上方或超出范围：直接归零
    spring.setPosition(0, 0);
    continue;
  }
  final delayStart = _delayStartTimes[i];
  if (delayStart != null) {
    final elapsed = (_lastElapsed.inMicroseconds / 1000.0) - delayStart;
    final delay = (i - _currentLineIndex) * _perLineDelayMs;
    if (elapsed >= delay) {
      spring.tick(dt);
    }
    // 延迟未到：保持初始偏移（setPosition 已设置）
  }
}
```

#### 新增辅助方法
```dart
Spring _getOrCreateSpring(int index) {
  return _perLineSprings.putIfAbsent(index, () => Spring(
    mass: _perLineSpringMass,
    damping: _perLineSpringDamping,
    stiffness: _perLineSpringStiffness,
    initialPosition: 0,
  ));
}
```

#### 新增字段
```dart
int _previousLineIndex = -1;
```

#### 构建 `_LyricsPainter` 时传入 perLineOffsets

#### 新增 `_buildPerLineOffsets` 方法
```dart
List<double> _buildPerLineOffsets() {
  return List.generate(widget.lines.length, (i) {
    return _perLineSprings[i]?.position ?? 0.0;
  });
}
```

#### `paint` 方法修改行位置计算
```dart
// 原来：
final double y = _topOf(i) + _interludeOffsetBefore(i) + posY;
// 改为：
final double offset = (i < perLineOffsets.length) ? perLineOffsets[i] : 0.0;
final double y = _topOf(i) + _interludeOffsetBefore(i) + posY + offset;
```

## 关键参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| `_perLineDelayMs` | 50ms | 相邻行间的级联延迟 |
| `_perLineOffset` | -40px | 每行初始偏移（负=向下，弹簧拉回0=向上） |
| `damping` | 15.0 | 欠阻尼，有轻微过冲 |
| `stiffness` | 100.0 | 中等刚度，~300ms 到位 |

## 验证
1. 播放歌词，切行时下方歌词逐级延迟上移，上方歌词无延迟
2. 快速连续切行，级联正确重置
3. 用户拖动歌词后松手，5s 回弹期间级联正常工作
4. 间奏期间歌词偏移正确
5. 横屏/平板布局正常
6. 无性能问题（弹簧仅 tick 视口附近的行）
