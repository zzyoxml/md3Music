# 歌词界面：当前行清晰 → 边缘递增高斯模糊

## 目标
将 AM 风格播放器歌词的上下 alpha 渐变淡出改为**从当前播放行向外递增的高斯模糊**：当前行完全清晰，离当前行越远越模糊。

## 现状
`lib/widgets/apple_lyrics/apple_lyrics_view.dart` 行 527-541 使用 `ShaderMask` + `LinearGradient` + `BlendMode.dstIn` 在顶部 15% 和底部 15% 做 alpha 淡出。

## 关键坐标
- 当前行对齐位置：`LyricLayout.alignPosition = 0.35`（视口高度 35% 处）
- 当前行屏幕 Y：`lineTops[currentLineIndex] + posY + mainLineHeight / 2`
- 稳态时约等于 `viewportHeight * 0.35`
- 用户手动拖动时会偏离，5s 后回弹

## 实现方案：Stack + 动态 BackdropFilter

### 布局结构
```
ClipRect
└── Stack
    ├── CustomPaint（歌词绘制，无 ShaderMask）
    └── 动态 BackdropFilter 模糊层（6 层，基于当前行位置计算）
```

BackdropFilter 作用于其下方 Paint Order 的内容，包括歌词文字。由于背景封面已 sigma=50 模糊，额外叠加影响极小，主要视觉效果在歌词文字上。

### 模糊分区（基于距当前行的垂直距离）

| 区域 | 距当前行距离 | sigma | 说明 |
|------|-------------|-------|------|
| 清晰区 | 0 ~ lineHeight×1.5 | 0 | 当前行及紧邻行 |
| 轻微模糊 | lineHeight×1.5 ~ 80px | 3 | 过渡区 |
| 中等模糊 | 80 ~ 160px | 8 | 次外层 |
| 强模糊 | 160px ~ 视口边缘 | 16 | 最外层 |

### 修改文件
`lib/widgets/apple_lyrics/apple_lyrics_view.dart`

### 具体改动

1. **移除 ShaderMask**（行 527-541）：删除 `shaderCallback`、`blendMode: BlendMode.dstIn`

2. **新增 `_buildBlurLayers` 方法**：
   - 接收 `viewportHeight`、`lineHeight` 参数
   - 计算当前行屏幕 Y = `lineTops[_currentLineIndex] + posY + mainLineHeight / 2`
   - 构建 6 个 `Positioned` + `ClipRect` + `BackdropFilter` 层
   - 每层裁剪到特定垂直区域，施加对应 sigma 的高斯模糊

3. **重组 Widget 树**：
   ```dart
   child: ClipRect(
     child: Stack(
       children: [
         CustomPaint(painter: _LyricsPainter(...), size: Size.infinite),
         ..._buildBlurLayers(viewportHeight, mainLineHeight),
       ],
     ),
   ),
   ```

4. **`_buildBlurLayers` 实现要点**：
   - 当前行屏幕 Y = `_lineTops[_currentLineIndex] + _scrollController.posY + mainLineHeight / 2`
   - 清晰区：从 `currentY - clearRadius` 到 `currentY + clearRadius`
   - 上方模糊层：从清晰区上边界到视口顶部
   - 下方模糊层：从清晰区下边界到视口底部
   - 使用 `Positioned(top:, left: 0, right: 0, height:)` 定位每层

## 用户交互：滑动时模糊消失

### 行为
- 用户开始拖动歌词 → 模糊强度在 ~200ms 内衰减到 0（所有 sigma → 0）
- 用户松手后 → 等待 5s 自动回弹期间保持无模糊
- 回弹动画开始 → 模糊在 ~300ms 内恢复到正常强度

### 实现
- 新增 `_blurIntensity` 动画值（0.0 ~ 1.0），控制所有 sigma 的乘数
- 用户拖动时：`onVerticalDragUpdate` 中将 `_blurIntensity` 快速插值到 0
- 回弹触发时：`_returnToCurrentLine` 中将 `_blurIntensity` 插值回 1.0
- 每层 sigma = `baseSigma * _blurIntensity`
- 用 `setState` 在拖动期间每帧更新（因为拖动本身就在触发重绘，无额外开销）

### 关键文件改动
`lib/widgets/apple_lyrics/apple_lyrics_view.dart`：
- `_onVerticalDragUpdate` 中设置 `_blurIntensity = 0`
- 新增 `_restoreBlur()` 方法，在回弹时启动 AnimationController 将 `_blurIntensity` 从 0 → 1（300ms）
- `_buildBlurLayers` 中每层 sigma 乘以 `_blurIntensity`

## 验证
1. 播放歌词，当前行清晰，上下行逐渐模糊
2. 手动拖动歌词 → 模糊快速消失，歌词完全清晰
3. 松手后等待期间保持无模糊
4. 5s 回弹动画期间模糊渐进恢复
5. 切歌时当前行切换，模糊区域跟随平滑过渡
6. 横屏/平板布局同样生效
7. 无明显卡顿
