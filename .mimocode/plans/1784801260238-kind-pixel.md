# 修复 UI 缩放导致的 Bottom Overflowed 问题

## 问题
UI 缩放开到 2.0x 时，发现页等页面出现 "bottom overflowed by xx pixels" 错误。
根因：多个区域使用固定高度容器（`SizedBox(height: N)`、`Container(height: N)`），文字放大后超出固定高度。

## 溢出点分析（按严重程度排序）

| 优先级 | 文件 | 行号 | 组件 | 问题 |
|--------|------|------|------|------|
| 1 | `discover_page.dart` | ~278 | `Container(height: 160)` banner | 160px 固定，headlineMedium+bodyLarge 放大后溢出 |
| 2 | `discover_page.dart` | ~364 | `SizedBox(height: 64)` ActionChip 行 | 64px 固定，Chip 放大后超出 |
| 3 | `album_card.dart` | ~66 | `SizedBox(height: 52)` 信息区 | 52px 固定，两行文字放大后溢出 |
| 4 | `discover_page.dart` | ~433 | `SizedBox(height: 170)` 主题音乐 | 170px 固定，卡片文字放大后可能溢出 |
| 5 | `discover_page.dart` | ~523 | `SizedBox(height: 100)` 场景音乐 | 100px 固定，图标+文字接近极限 |
| 6 | `user_center_page.dart` | ~598 | 日历 `cellSize=40` | 日期数字放大后溢出 32px 圆形 |

## 修复方案

### 方案：将固定高度改为自适应高度

核心思路：把 `SizedBox(height: N)` 改为 `ConstrainedBox` 或直接去掉固定高度，让内容自适应。

#### 1. 发现页 banner（`discover_page.dart` ~278）
- `Container(height: 160)` → 去掉固定 height，改为 `Padding` 包裹，让内容撑高
- 或改为 `ConstrainedBox(constraints: BoxConstraints(minHeight: 160))`，允许更大

#### 2. ActionChip 行（`discover_page.dart` ~364）
- `SizedBox(height: 64)` → `SizedBox(height: 72)` 或改为 `ConstrainedBox(minHeight: 64)`
- ActionChip 本身应有合理的 intrinsic height，只需给够空间

#### 3. AlbumCard 信息区（`album_card.dart` ~66）
- `SizedBox(height: 52)` → 去掉固定高度，改为 `Padding` + `ConstrainedBox(minHeight: 44)`
- 让文字自然撑高

#### 4. 主题音乐（`discover_page.dart` ~433）
- `SizedBox(height: 170)` → `SizedBox(height: 180)` 或使用 `AspectRatio` 替代

#### 5. 场景音乐（`discover_page.dart` ~523）
- `SizedBox(height: 100)` → `SizedBox(height: 110)`

#### 6. 日历格子（`user_center_page.dart` ~598）
- `cellSize = 40.0` → `cellSize = 44.0`，32px circle → 36px

### 通用兜底策略
在所有修改点使用 `ConstrainedBox(constraints: BoxConstraints(minHeight: X))` 而非固定高度，确保：
- 缩放 1.0x 时布局不变
- 缩放 > 1.0x 时容器能扩展

## 修改文件清单
1. `lib/modules/discover/discover_page.dart` — banner、Chip行、主题音乐、场景音乐
2. `lib/widgets/album_card.dart` — 信息区固定高度
3. `lib/modules/user/user_center_page.dart` — 日历格子大小

## 验证
1. 设置 UI 缩放为 1.0x → 布局与修改前完全一致
2. 设置 UI 缩放为 1.5x → 各页面无溢出
3. 设置 UI 缩放为 2.0x → 各页面无溢出（文字大但不崩溃）
4. 发现页滚动流畅，无白屏/重叠
