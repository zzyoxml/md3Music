# 设备类型自动识别 + 播放列表对话框适配

## 目标
1. 新增 `DeviceProvider`，自动识别手机/Pad 并支持用户手动切换
2. 设置页添加设备类型选择器（自动/手机/Pad）
3. 播放列表对话框根据设备类型自适应尺寸
4. 替换 FullPlayer 中硬编码的 `width >= 600` 检测逻辑

---

## 修改文件清单

### 1. 新建 `lib/providers/device_provider.dart`

```dart
enum DeviceType { auto, phone, pad }

class DeviceProvider extends ChangeNotifier {
  // SharedPreferences key
  static const String _key = 'device_type';

  DeviceType _deviceType = DeviceType.auto;
  DeviceType get deviceType => _deviceType;

  // 实际生效的设备类型（auto 模式下自动检测）
  bool get isPad {
    switch (_deviceType) {
      case DeviceType.auto:
        return _autoDetect();
      case DeviceType.phone:
        return false;
      case DeviceType.pad:
        return true;
    }
  }

  // 自动检测：最短边 >= 600dp → Pad
  bool _autoDetect() {
    final view = WidgetsBinding.instance.platformDispatcher.views.first;
    final size = view.physicalSize / view.devicePixelRatio;
    return size.shortestSide >= 600;
  }

  // 构造函数加载持久化值
  DeviceProvider() { _load(); }

  Future<void> _load() async {
    final prefs = await SharedPreferences.getInstance();
    final index = prefs.getInt(_key) ?? 0;
    _deviceType = DeviceType.values[index.clamp(0, 2)];
    notifyListeners();
  }

  Future<void> setDeviceType(DeviceType type) async {
    if (_deviceType == type) return;
    _deviceType = type;
    notifyListeners();
    final prefs = await SharedPreferences.getInstance();
    await prefs.setInt(_key, type.index);
  }
}
```

### 2. 修改 `lib/app.dart`

- 导入 `device_provider.dart`
- 在 MultiProvider 中注册 `ChangeNotifierProvider(create: (_) => DeviceProvider())`

### 3. 修改 `lib/modules/settings/settings_page.dart`

在 `_buildAppearanceSection()` 的 AM 风格播放页开关之后（line ~388）、`SizedBox(height: 8)` 之前，添加设备类型选择器：

```dart
// 设备类型选择
Padding(
  padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 8),
  child: Row(
    children: [
      Expanded(
        child: Text('设备类型', style: Theme.of(context).textTheme.bodyLarge),
      ),
    ],
  ),
),
Padding(
  padding: const EdgeInsets.symmetric(horizontal: 16),
  child: SegmentedButton<DeviceType>(
    segments: const [
      ButtonSegment(value: DeviceType.auto, label: Text('自动'), icon: Icon(Icons.brightness_auto)),
      ButtonSegment(value: DeviceType.phone, label: Text('手机'), icon: Icon(Icons.smartphone)),
      ButtonSegment(value: DeviceType.pad, label: Text('Pad'), icon: Icon(Icons.tablet)),
    ],
    selected: {_deviceType},
    onSelectionChanged: (modes) {
      final type = modes.first;
      setState(() => _deviceType = type);
      context.read<DeviceProvider>().setDeviceType(type);
    },
  ),
),
```

需要在 State 中添加 `DeviceType _deviceType = DeviceType.auto;` 字段，并在 `_loadSettings()` 中从 DeviceProvider 读取。

### 4. 修改 `lib/widgets/player_playlist_dialog.dart`

在 `build()` 方法中，将硬编码的 60% 改为根据设备类型计算：

```dart
@override
Widget build(BuildContext context) {
  final size = MediaQuery.sizeOf(context);
  final theme = Theme.of(context);
  final isPad = context.read<DeviceProvider>().isPad;

  // Pad: 60% 宽高；手机: 90% 宽高
  final double width = size.width * (isPad ? 0.6 : 0.9);
  final double height = size.height * (isPad ? 0.6 : 0.9);

  // ... 其余不变
}
```

### 5. 修改 `lib/modules/player/full_player.dart`

替换 `_checkPadMode()` 中硬编码的 `width >= 600` 为使用 DeviceProvider：

```dart
void _checkPadMode() {
  if (!mounted) return;
  final width = MediaQuery.sizeOf(context).width;
  final shouldBePadMode = context.read<DeviceProvider>().isPad || width >= 600;
  // ... 其余逻辑不变

```

> 注：保留 `width >= 600` 作为 landscape 布局的兜底判断（横屏时物理宽度可能 >= 600 但实际是手机横屏），同时优先使用 DeviceProvider 的判断。

## 验证方式

1. `flutter analyze` 无新 error/warning
2. 设置页 → 外观 → 底部出现「设备类型」SegmentedButton（自动/手机/Pad）
3. 切换为「手机」→ 播放列表对话框变为 90% 宽高
4. 切换为「Pad」→ 播放列表对话框变为 60% 宽高
5. 切换为「自动」→ 根据设备最短边自动判断
6. 手机竖屏播放器 Tab 数量保持 3 个（封面/歌词/评论）
7. Pad 横屏播放器 Tab 数量为 2 个（歌词/评论）
